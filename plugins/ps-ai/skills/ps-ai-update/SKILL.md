# Update ps-ai

Never use this skill in legion mode. It does not need repository setup or an overseer lease. A session notice only offers an update; it does not authorize one.

Speak to the owner in plain words. Show a command only when they ask for it or must run it themselves.

1. Run a fresh check, even after a session notice, using [commands.md](references/commands.md).
2. Tell the owner the installed and available versions. If no newer version is available, say so and stop. If the check fails, explain that the versions could not be confirmed; use the fallback in the reference without claiming a version you could not read.
3. Ask whether they want to update ps-ai. Update only after the owner's yes. If they decline, stop.
4. After a successful update, tell them the new skills load after they restart the session. Follow the selected tool skill for how to restart or resume with the same account and repository folder. If the update fails, explain what failed and what remains to be done.
