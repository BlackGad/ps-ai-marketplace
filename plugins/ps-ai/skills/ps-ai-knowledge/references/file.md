# File a reusable lesson

Write the general problem, the cause or decision with its reason, the solution, and when to use it again. Tag it with `projects.<repo-id>.label` from personalisation, never a client name. File after a hard problem and during milestone close-out.

Before and after writing, check:

- [ ] No client names or identifying project names.
- [ ] No source code or proprietary snippets.
- [ ] No hosts, domains, URLs, IP addresses, or physical/email addresses that identify a client.
- [ ] No secrets, credentials, tokens, or credential file contents.
- [ ] The project tag is only the neutral `label`.

Replace specifics with roles such as “the service” or “the readiness signal.” If removing specifics destroys the lesson, drop it. A behavior-changing lesson also belongs in `ps-ai-notes.md`.
