# Markdown fallback

Read the hub and topic `_index.md` files, then search and open relevant Markdown notes. Cite the note path in the answer.

For a new note, pick the relevant topic wiki, place a sanitised raw Markdown note in that topic's `inbox/`, and leave it for the next llm-wiki compile. Do not put a content `inbox/` at the hub root. If no topic or inbox exists, report that filing is pending setup; do not invent a wiki structure. Re-read the raw note and apply [file.md](file.md) before considering it filed. Then commit the note in the hub as [file.md](file.md) says.
