# Overseer launcher

For commands, use `legion <verb>` from PATH. If the command is unavailable, finish setup first and open a fresh terminal. See the [setup guide](create.md). Every account starts through `legion run`. See the [task loop](../../legion-overseer/references/task-loop.md#legion-run-and-updates) for how updates affect running accounts.

Usage: `legion [--account <id>] [--tool <tool-id>] [--channel <id> [--channel <id> ...]] [--no-channel] [--argument=<word>] [--repo <path>]`.

Bare `legion` with no account, tool, channel or arguments repeats the last launch in that repository, including a launch without channels; adding only `--no-channel` (or `legion pick` choosing the saved account) restores the saved account and arguments, then clears the channel. Legion saves the last account, channels and arguments for each repository and remembers the last session for each account in that repository. It asks the selected tool to resume the session. If no saved launch has an account that still exists, a bare `legion` uses the account that last held the repository's overseer lease, if it still exists. Otherwise, one eligible account (after `--tool` and `--channel` narrowing) is picked; with several, the launcher asks which account leads; without a console it lists the ids and stops. Choose with `legion pick`, which lists the accounts and asks, or the launcher's `--account <id>`. When exactly one channel binding fits the account and the tool, it is added by default; `--no-channel` skips it and `--channel <id> [--channel <id> ...]` overrides it. On success it prints `launched <id> (<tool>) in <repo>`.

Omit model flags by default. When owner notes name a model or allow a tier, follow [model tiers](../../legion-overseer/references/task-loop.md#model-tiers) and pass the flag through literal `--argument`, for example `legion --account <id> --tool <tool> --repo <repo> --argument=--model --argument='<named-model>' --argument='two words' --argument=''`. Follow [owner notes](fields.md) for account and channel choices; prefer the current account when bound and its session tools are available, otherwise name a supported bound alternate before an authorized relaunch. A direct launcher run is itself a request to launch; simulations describe actions without running them. Any owner-started session may take the lease without a channel. Follow the overseer communication guide's handoff, release, launch and stop order. On Windows the launcher uses Terminal when available; otherwise it runs in the current terminal. Both paths clear `NO_COLOR`, `TERM` and the calling Claude session's variables (`CLAUDECODE`, `CLAUDE_CODE_*`) for the new session, so the overseer is saved as its own session and can be resumed. Always launch through this command, never a hand-built terminal command.

Account, channel and repository verbs run through this owner command: `legion account add --id <id> --tool <tool>`, `legion remove --id <id>`, `legion channel add --id <id> --kind telegram --target <chat> --account <account>`, `legion channel check --kind telegram --account <account>`, `legion channel remove --id <id>`, and `legion repository setup --repo <path>`.
